# 本桌村规

游戏使用固定的 108 张牌：四种颜色各 25 张（一个 0、1–9 各两张、禁止/反转/+2 各两张），另有 4 张万能变色牌和 4 张 +4。开局翻出数字牌；先出完手牌的人获胜。

本项目的「经典规则」包含明确的简化约定：没有 +4 质疑流程，漏喊 UNO 立即罚摸。它是游戏内的规则预设，不声称完整复刻官方所有赛制。

## 九项设置

| 设置            | 可选值             | 经典默认 | 本项目的准确语义                                                                                                     |
| --------------- | ------------------ | -------- | -------------------------------------------------------------------------------------------------------------------- |
| 起始手牌        | 3–15 张            | 7        | 每位玩家相同张数；整局牌数始终为 108                                                                                 |
| 罚牌叠加        | 不叠 / 同类 / 混叠 | 不叠     | 不叠时下位立即摸罚牌并跳过；同类允许 +2 接 +2、+4 接 +4，不要求同色；混叠允许 +2/+4 相接。承受罚牌时摸总额并结束回合 |
| 摸牌方式        | 一张 / 摸到能出    | 一张     | 摸后只能出最后摸到的那张或跳过；「摸到能出」耗尽可用牌仍无可出牌时自动跳过；普通出牌前也允许主动摸牌                 |
| 摸后必出        | 开 / 关            | 关       | 最后摸到的牌可出时不能跳过；不强制玩家点击摸牌后立即自动出牌，仍可选择万能牌颜色等                                   |
| 7 换手 · 0 轮转 | 开 / 关            | 关       | 非收尾的 7 与指定玩家交换手牌；非收尾的 0 让全部手牌沿当前出牌方向轮转                                               |
| 同牌抢出        | 开 / 关            | 关       | 非当前玩家可抢出与顶牌同色、同数字或同功能的普通牌；万能牌不可抢出；存在待承受罚牌时不可抢出                         |
| +4 严格限制     | 开 / 关            | 开       | 开启时，手里没有当前颜色才能出 +4；同数字/功能但不同色不阻止 +4。此限制在叠加时同样生效；不提供质疑流程              |
| 漏喊 UNO 罚牌   | 0 / 2 / 4 张       | 2        | 两张牌出到一张前须先按 UNO；漏喊立即罚摸，无需其他玩家抓包。程序内部也支持出牌动作携带 UNO 声明                      |
| 功能牌收尾      | 开 / 关            | 开       | 开启时任意合法牌可收尾；关闭时最后一张必须是数字牌，万能牌和功能牌都不能作为最后一张打出                             |

| 设置        | 经典规则 | 休闲派对 | 欢乐混战   |
| ----------- | -------- | -------- | ---------- |

| 罚牌叠加    | 不叠加   | 同类叠加 | +2/+4 混叠 |

## 功能牌与边界

- **禁止**：跳过下一位。
- **反转**：改变方向；双人局等价于跳过对手，出牌者继续。
- **+2 / +4**：不叠加时下位摸牌并跳过；允许叠加时累积到下位，直到有人接不住或选择摸罚牌。+4 需选择颜色。
- **万能变色**：选择下一种颜色，不能用于承接待结算的罚牌。
- **7/0**：最后一张为数字 7 或 0 时先判胜，不再交换。交换获得单张手牌的玩家自动宣告 UNO；交换后的新手牌无需事先预测并喊 UNO。
- **收尾罚牌**：最后一张是合法 +2/+4 时仍向下位结算罚牌（含已累积罚牌），然后结束对局，不再给其他玩家叠加机会。
- **牌堆耗尽**：保留顶牌，重洗其余弃牌。仍无牌可摸时跳过；不足罚摸总数时只能摸实际可用的牌。
- **摸后抢出**：开启抢出时，别人可以在当前玩家摸牌后抢出完全相同的普通牌；抢出者接管出牌位置，随后正常结算并推进方向。

## 人机与在线

人机对战的村规在「按这个规则开一局」时生效；进行中的对局保留原配置。三档 AI 使用相同合法性规则，难度影响选牌策略，不读取人类隐藏手牌来作弊。

快速匹配固定项目经典规则，两位真实账号匹配后开始。好友房支持 2–4 位玩家；房主开局前调整规则，其他成员可以查看，开局后服务器锁定规则。所有在线动作都由服务器使用这份配置判定。

联机每回合 45 秒。超时自动摸牌并跳过；已摸牌则跳过。若本桌开启摸后必出，服务器自动合法打出可出的摸牌，并选择颜色/交换对象；承受叠罚牌直接结束该回合。喊 UNO 不延长计时。有效出牌（包括抢出、双人禁止/反转）开启新的回合计时。

掉线保留座位 60 秒；在此期间重新连接恢复对局。超过时限或主动离开时移除玩家，手牌返回牌堆；剩一位玩家则其获胜。账号、服务器与部署细节见 [ONLINE.md](ONLINE.md)。
